# NOTICE | PDN DEX Stablecoins

**PDN DEX Stablecoins** is a stablecoin-focused deployment of the original PDN DEX.

The core DEX functionality, architecture, mechanisms, and operating principles remain unchanged. The only functional difference is the set of supported tokens configured in the smart contract. The interface is labeled **PDN DEX Stablecoins** to distinguish this deployment.
